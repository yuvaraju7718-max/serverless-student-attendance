Key Architectural Highlights

  • Zero Server Maintenance: Built on Firebase Serverless architecture (Hosting + Auth + Firestore + Cloud Functions).
  • Deterministic Duplicate Prevention: Guarantees no duplicate records for the same student, subject, class, and date.
  • Strict Role-Based Authorization: Enforced at the database level with Cloud Firestore Security Rules.
  • Automated Calculation: Real-time attendance percentage computation per subject and overall.
